# Sistema Help Desk - Backend API
## Descripción
Proyecto desarrollado para la asignatura Desarrollo de Sistemas Informáticos.
El sistema implementa una API REST utilizando Node.js, Express y PostgreSQL para la gestión de incidentes tecnológicos de un Data Center.
---

## Tecnologías utilizadas
- Node.js
- Express
- PostgreSQL
- Postman
- Git
- GitHub

## Instalación
### Clonar el repositorio
git clone <URL_REPOSITORIO>

### Entrar al backend
cd backend

### Instalar dependencias
npm install

### Ejecutar el servidor
npm run dev
